# 2D Unity Game 

A complete 2D game developed in Unity, focused on gameplay mechanics, responsive UI design, optimization, and clean game architecture. This project represents my practical learning journey in game development.

## About The Project

This project was built as part of my journey to become a professional Unity Game Developer. The main goal was to create a polished and structured 2D game while improving my understanding of gameplay programming, UI responsiveness, game logic, and performance optimization.

The game includes multiple reusable systems and organized code architecture to keep development scalable and maintainable.


## Improvements Needed

This game will keep improving with time. The goal is to make it smoother, more fun, and more visually polished.

Planned improvements include:

- Better **parallax background effects** to make the game look more deep and alive.
- Smoother **game performance and movement feel**.
- Improved **graphics rendering and visual quality**.
- Better **optimization** so the game runs smoothly on all mobile devices.
- Adding **more levels** (currently only 1 level exists).
- Introducing **new enemies** as more levels are added.
- Better **environment design and level detailing**.
- As levels progress, the game will gradually become more challenging.
- New hurdles and obstacles will be added in future levels.

### Open for Contributions

Contributors are welcome to improve the **visual side of the game**, including:

Follow these steps to contribute:

### 1. Clone the Repository

Open Git CLI / Terminal and run:

```bash
git clone https://github.com/alifakahr186/Ninja-Shadow.git
```
To avoid compatibility issues, install the required Unity version:

```Unity Version: 6000.0.37f1```

After installing Unity:
- Open Unity Hub
- Click Add Project From Disk
- Select the cloned project folder

## Restriction
The goal of this project is to keep a **consistent gameplay experience**, while allowing improvements in performance, visuals, and level expansion without changing the core structure of the game.
